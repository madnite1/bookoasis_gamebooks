Game Books 설정

게임 플레이 중 세이브(.sav / .state)를 서버(plugins/data/bookoasis_gamebooks/saves/user_{id}/)에 유저별로 실시간 보관합니다.
플레이 중 브라우저 세이브를 서버로 전송하는 간격입니다.
EmulatorJS 관련 데이터를 관리할 기준 루트 디렉터리입니다.

영속 저장소 경로 안내 (유저별 격리)

  • 설정 및 DB: plugins/data/bookoasis_gamebooks/gba.db
  • 공유 롬 저장소: plugins/data/bookoasis_gamebooks/roms/ (또는 추가 지정 경로)
  • 바이오스 파일: plugins/data/bookoasis_gamebooks/bios/ (또는 사용자 지정 경로)
  • 커버 이미지: plugins/data/bookoasis_gamebooks/covers/ (또는 사용자 지정 경로)
  • 유저 세이브 파일: plugins/data/bookoasis_gamebooks/saves/user_{user_id}/

고급 라이브러리 관리

삭제 대기 게임의 실제 파일을 먼저 정리한 뒤 기존 ROM 분석 캐시를 무시하고 모든 ROM을 최신 분석 기준으로 다시 판정하며, 상세 분석 원본과 카드 진단 상태를 같은 결과로 새로 만듭니다. 필요하면 기종 폴더 이동·7z→ZIP 변환까지 수행합니다. 일반적인 ROM 추가/삭제에는 위의 라이브러리 동기화를 사용하세요.

삭제 대기 관리

여기에 있는 게임은 일반 목록에서 숨겨져 있지만 ROM 파일은 아직 남아 있을 수 있습니다. 라이브러리 동기화 또는 전체 재구축에서 실제 삭제를 처리합니다.
